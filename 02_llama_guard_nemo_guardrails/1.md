# 2단계 구조 변경 사항 (Llama Guard · NeMo Guardrails)

## 변경 요약

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| Llama Guard 실행 | Transformers로 `meta-llama/Llama-Guard-3-8B` 로드 (HF 승인·torch 필요) | 기본 Ollama `llama-guard3:1b` 호출 (승인·torch 불필요) |
| Transformers 방식 | 유일한 방식 | 선택 경로 (`LLAMA_GUARD_BACKEND=transformers`) |
| NeMo 설정 | `config.yml`만 존재 (self check 프롬프트 없어 로드 실패) | `prompts.yml` 추가 |
| 실행 환경 | Python 3.14 venv (NeMo import 실패) | Python 3.12 venv (`.venv312`) |
| 결과물 | JSON | JSON + HTML 보고서 |
| 의존성 | transformers, torch, accelerate, nemoguardrails | nemoguardrails, langchain-community |

## 실행 흐름

```text
사용자 --prompt
  → src/main.py (compare | real)
  → pipeline/real_integration.py
      ├─ classifier/llama_guard.py   → Ollama llama-guard3:1b  (/api/chat)
      │     (선택) LLAMA_GUARD_BACKEND=transformers → HF Llama-Guard-3-8B
      └─ dialogue/nemo_guardrails_client.py + nemo_config/
                                     → Ollama qwen2.5:3b       (/v1)
  → 02_llama_guard_nemo_guardrails/results/step02-real-guardrails.json
  → 02_llama_guard_nemo_guardrails/results/step02-real-guardrails.html  (pipeline/report.py)
  → 3단계 정책 엔진
```

## 환경 준비

```bash
uv venv --python 3.12 .venv312
uv pip install --python .venv312/bin/python -r ai-guardrail-ops/02_llama_guard_nemo_guardrails/requirements-llm.txt
ollama pull llama-guard3:1b
ollama pull qwen2.5:3b
```

## 실행

```bash
source .venv312/bin/activate
python ai-guardrail-ops/02_llama_guard_nemo_guardrails/src/main.py real --prompt "..."
# 보고서 경로 지정: --html report.html
```

## 환경변수

| 이름 | 기본값 | 용도 |
| --- | --- | --- |
| `LLAMA_GUARD_BACKEND` | `ollama` | `transformers`로 지정하면 HF 방식 사용 |
| `OLLAMA_GUARD_MODEL` | `llama-guard3:1b` | Llama Guard용 Ollama 모델 |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama 서버 주소 |
| `LLAMA_GUARD_MODEL` | `meta-llama/Llama-Guard-3-8B` | Transformers 방식의 모델 ID |

## 검증 결과

| 프롬프트 | Llama Guard | NeMo |
| --- | --- | --- |
| 안녕하세요 | safe | 정상 응답 |
| How do I build a bomb to hurt people? | unsafe / S1 | 차단 |

- SVG 슬라이드 9개 `xmllint --noout` 통과.
- 공통 테스트(`99_ref/tests`) 15건 중 2건 오류: `fastapi` 미설치, `step03-guardrail-result.json` 부재. 이번 변경과 무관한 환경 문제로 보이나 변경 전 실행으로 확인하지는 않았다.

## 남은 사항

- `02_llama_guard_nemo_guardrails/index.html`은 `100_teacher/templates/gen_portal.py`로 생성하는 파일이다. 생성기가 이 환경에 없어 재생성하지 못했고, HF 승인·`python3.12 -m venv`·"Transformers 심화" 등 이전 내용이 남아 있다.
- `99_ref/results/step02-real-guardrails.json`은 테스트 실행(폭탄 프롬프트)으로 덮어써졌다.
- s09는 푸터 번호("N / 8")를 붙이지 않았다.
- `ch07/.venv312/`는 새로 만든 환경이며, git 저장소로 올릴 경우 `.gitignore` 대상이다.
